# Neon Snake 🐍

A fun and cool neon-styled Snake game made by Grok!

## How to Play
- Use **Arrow Keys** to control the snake.
- Eat the glowing pink food to grow and score points.
- Avoid hitting walls or yourself!

## Play It
Open `index.html` in any browser, or visit the GitHub Pages if enabled.

Made with pure HTML, CSS, and JavaScript. No dependencies!

Enjoy! 🎮
